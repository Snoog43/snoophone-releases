# Snoophone

Snoophone est une version modifiée de NectarLink (https://github.com/thtbee/nectarlink),
distribuée sous les mêmes licences (GPL-3.0-or-later pour les applications, MPL-2.0 pour le cœur).
Modifications : nom, logo, pas de mise à jour automatique, pas de démarrage avec Windows par défaut,
rendu de l'interface dans son propre fil.
