# Snoophone

Ton téléphone Android sur ton PC Windows : notifications, messages, appels, fichiers, presse-papiers, photos, écran du téléphone et webcam.

## Installer sur le PC

Colle cette ligne dans PowerShell :

```powershell
irm https://raw.githubusercontent.com/Snoog43/snoophone-releases/main/install.ps1 | iex
```

Ou télécharge [Snoophone-x64-setup.exe](https://github.com/Snoog43/snoophone-releases/releases/latest/download/Snoophone-x64-setup.exe).

## Installer sur le téléphone

Télécharge [Snoophone-android.apk](https://github.com/Snoog43/snoophone-releases/releases/latest/download/Snoophone-android.apk) sur le téléphone et ouvre-le (autorise l'installation depuis le navigateur si Android le demande). Ouvre ensuite Snoophone sur le PC et sur le téléphone pour les appairer.
